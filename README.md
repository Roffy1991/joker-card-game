# 小丑牌 Web V1.0.0

基于扑克牌型的单机数值小游戏，灵感来自 Balatro。  
本项目是「AI 全流程开发」课堂第一课的课堂演示成果——从 PRD 到 DESIGN 再到可运行代码，全程由 AI 辅助完成。

## 游戏规则

- 标准 52 张牌，每局初始发 **8 张**手牌
- **4 次出牌机会 + 3 次弃牌机会**
- 累计得分 ≥ **300 分**即胜利，出牌耗尽仍不足则失败
- 出牌得分公式：`(牌型基础分 + 所有选中牌点数之和) × 倍数`

| 牌型 | 基础分 | 倍数 |
|------|--------|------|
| 高牌 | 5 | ×1 |
| 对子 | 10 | ×2 |
| 两对 | 20 | ×2 |
| 三条 | 30 | ×3 |
| 顺子 | 30 | ×4 |
| 同花 | 35 | ×4 |
| 葫芦 | 40 | ×4 |
| 四条 | 60 | ×7 |
| 同花顺 | 100 | ×8 |
| 皇家同花顺 | 100 | ×8 |

## 运行方式

无需安装任何依赖，直接用浏览器打开即可：

```bash
open game.html
# 或双击 game.html 文件
```

## 目录结构

```
.
├── game.html       # 游戏主体（全量 HTML/CSS/JS，单文件）
├── PRD.html        # 产品需求文档
├── DESIGN.html     # UI 设计规范
├── agents/         # 自定义 Claude Agent 角色定义
└── slash/          # 自定义 Claude 斜杠命令
```
